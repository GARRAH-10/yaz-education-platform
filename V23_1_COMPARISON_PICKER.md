# V23.1 — Comparison Picker UX

The original V23 comparison selection persisted across searches, but that was not obvious when a filtered page showed only one matching programme.

V23.1 adds an explicit **Add another programme** action to the sticky comparison tray.

- Opens a programme picker without losing the current selection.
- Prioritises programmes with the same field and study level as the first selected programme.
- Allows free-text search by programme, university, field, location, or specialisation.
- Supports up to three selected programmes.
- Compare Now becomes available as soon as two programmes are selected.
- Works in English and Arabic and has a mobile bottom-sheet layout.
